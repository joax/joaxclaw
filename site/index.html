Your gateway, under control.

JoaxClaw is a desktop app for an OpenClaw gateway — chat with your agents, build multi-agent teams, schedule jobs, and manage models, channels, and plugins. Local or remote, it's your gateway and your machine.

What's inside

Chat & agents

Streaming responses with reasoning blocks and tool-call visibility. Attach images, documents, and audio. Browse, search, and replay past sessions.

Teams & processes

A visual builder for multi-agent workflows with conditional branching and revision history, plus a live execution monitor.

Channels

Manage the messaging platforms your gateway talks on — scoped agent routing, multi-account, and a per-channel policy editor.

Scheduled jobs

Run an agent turn or an entire team on a cron schedule, unattended, with run history.

Models & local engines

Configure providers, track per-model cost, and detect or health-check Ollama, LM Studio, vLLM, llama.cpp, Jan, and KoboldCpp.

Remote gateways

Everything works against a gateway on another machine, over Tailscale or your LAN, via a companion plugin you install in one click.

Download

macOS

JoaxClaw.dmg {{MAC_SIZE}}

The build is currently unsigned, so macOS blocks it on first launch. Open System Settings → Privacy & Security → Open Anyway, or run:

sudo xattr -rd com.apple.quarantine /Applications/JoaxClaw.app

Linux

joaxclaw.deb {{LINUX_SIZE}}

Install it with:

sudo dpkg -i joaxclaw_*.deb
sudo apt-get install -f

Then launch JoaxClaw from your app menu.

You'll also need an OpenClaw gateway running locally or on a machine you can reach. Building from source? See the repository.
